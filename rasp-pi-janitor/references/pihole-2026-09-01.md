## Lessons / Caveats
- RPi OS does not create `/var/run/reboot-required` on kernel updates; detect a staged kernel by comparing `uname -r` to the newest `/lib/modules` entry (flavor-aware).
- `pihole -v` reports "N/A" when run as non-root after `sudo pihole -up`, due to git "dubious ownership" of root-owned repos; use `sudo pihole -v` for a clean read.
- `apt-get upgrade` alone does not pull new kernel packages on RPi OS; use `full-upgrade` / `--dist-upgrade` for kernel updates.
